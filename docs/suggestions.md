# Games to look at

The weekly scout opens every address below before anything else (see docs/scout.md, section 2)
and evaluates it by the usual rules. A game listed here still needs one independent source.

One game per line: its address, then a note if useful. Remove a line once the game has been
added, or once you no longer want it considered. To refuse a game for good, add its address
to src/data/rejected.json instead.
